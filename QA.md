# Проверка LoveLoom beta 0.2

Дата: 26 сентября 2026 года. Среда: Node.js 24, Linux, Chromium 153. Проверялась локальная версия, без облачных сервисов и реальных данных пользователей.

## Автоматические проверки

- TypeScript: `npm run typecheck`.
- Сервер: `npm test` — 13 проверок регистрации, уникальности пароля комнаты, лимита участников, изоляции данных, сохранения после повторного открытия базы, удаления истории, прав владельца, конфликтов редактирования, скрытия игровых ответов и прогнозов, согласия на геолокацию, хранения секретов, администратора и ограничения попыток.
- Production-сборка: `npm run build`.
- Браузер: `node scripts/browser-smoke.mjs` — две независимые сессии в отдельных процессах Chromium, десктоп 1440 px и мобильный viewport 390 px.
- Дизайн-бета: `npm run test:beta` — статическая сборка под `/loveloom`, рукописные шрифты, светлая/тёмная темы, шесть быстрых виджетов, сохранение их настроек, все шесть общих разделов, редактор заметки, панель истории, чат, переключение ролей, игра с двумя ответами, экран звонка и безопасный экран авторизации. Проверка также подтверждает отсутствие запросов к API и формы администратора в публичной сборке.

## Сценарий в браузере

1. Два новых аккаунта регистрируются через интерфейс.
2. Первый бесплатно создаёт комнату, второй входит по её паролю.
3. Сообщения обоих появляются у партнёра. Сохранение переписки после повторного открытия базы дополнительно проверено серверным тестом.
4. Третий аккаунт не может войти в заполненную комнату и получить её записи.
5. Заметка создаётся через интерфейс и остаётся после перезагрузки.
6. Запросы изменения данных с чужим Origin или без CSRF-токена отклоняются.
7. Приглашённый участник выходит; сервер очищает историю, создатель видит пустую комнату.
8. На основных экранах нет горизонтального переполнения; проверены светлая и тёмная темы. Не зарегистрированы необработанные ошибки JavaScript.

В `preview` приложены снимки фактически работающих экранов. Браузерные аккаунты и записи вымышлены, для каждого прогона создаётся временная база.

## Границы проверки

Это не аудит безопасности готового публичного продукта. Не проверены физические Android/iOS-устройства, Safari, установка PWA на телефон, поведение мобильной клавиатуры и фактическое разрешение GPS. Серверные правила геолокации и игр проверены тестами, но полный игровой интерфейс не покрыт браузерным сценарием. Нагрузочные и независимые security-проверки ещё не проводились.

Облачная база, восстановление доступа, фото/видео, звонки, фоновые уведомления, оплата и публикация отсутствуют; они не входят в перечень успешно проверенных функций этой сборки. Полный список ограничений и дальнейших этапов находится в `README.md`.
