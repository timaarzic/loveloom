# Фирменные письма LoveLoom

- Подтверждение: тема `Подтвердите почту — LoveLoom`, шаблон `confirmation.html`.
- Восстановление: тема `Восстановление доступа — LoveLoom`, шаблон `recovery.html`.
- Рекомендуемый отправитель после подключения домена: `LoveLoom <hello@домен>`.
- Обе кнопки используют одноразовый `{{ .ConfirmationURL }}` и содержат запасную текстовую ссылку.

Шаблоны нужно скопировать в Authentication → Emails → Templates. Их нельзя считать полностью фирменной почтой, пока в Supabase Auth не настроен собственный SMTP и подтверждён домен отправителя. Секрет SMTP хранится только в панели Supabase или переменных окружения, не в репозитории.
